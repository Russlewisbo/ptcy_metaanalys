Comparison 1: PTCy vs CNI+MTX/MMF

Comparison 1 evaluates PTCy against calcineurin inhibitor–based prophylaxis (CNI+MTX or CNI+MMF) — the most common alternative platform. This comparison draws on the largest evidence base in the meta-analysis.

Overall Survival

tibble(
  M1 = post_os$b_ptcy_binary,
  M2 = post_m2_os[[ptcy_col(post_m2_os)]]
) |>
  pivot_longer(everything(), names_to = "Model", values_to = "log_or") |>
  ggplot(aes(x = log_or, fill = Model, colour = Model)) +
  geom_density(alpha = 0.35, linewidth = 0.6) +
  geom_vline(xintercept = 0, linetype = "dashed", colour = jama_grey) +
  scale_fill_manual(values = c("M1" = jama_navy, "M2" = jama_steel)) +
  scale_colour_manual(values = c("M1" = jama_navy, "M2" = jama_steel)) +
  labs(x = "log-OR (PTCy vs CNI+MTX/MMF)", y = "Posterior density",
       title = "Overall Survival — Posterior Distributions") +
  theme_jama()

M1 (Direct effect): OR 0.77 (95% CrI 0.71–0.83), P(OR < 1) = 100%, τ = 0.59. The posterior is entirely below the null, indicating a consistent mortality reduction with PTCy.

M2 (Steroid-adjusted): Adjusting for arm-level systemic steroid exposure attenuated the OR from 0.77 to 0.83 (95% CrI 0.75–0.92), a 29% reduction in the log-OR. The residual benefit after adjustment indicates GVHD mediation does not fully explain the OS advantage.

med_data <- tibble(
  Outcome = rep(c("OS", "NRM"), each = 2),
  Model = rep(c("M1", "M2"), 2),
  or = c(
    median(exp(post_os$b_ptcy_binary)),
    median(exp(post_m2_os[[ptcy_col(post_m2_os)]])),
    median(exp(post_nrm$b_ptcy_binary)),
    median(exp(post_m2_nrm[[ptcy_col(post_m2_nrm)]]))

    quantile(exp(post_os$b_ptcy_binary), 0.025),

    quantile(exp(post_os$b_ptcy_binary), 0.975),
    quantile(exp(post_m2_os[[ptcy_col(post_m2_os)]]), 0.975),

    quantile(exp(post_m2_nrm[[ptcy_col(post_m2_nrm)]]), 0.975)

  mutate(label = sprintf("%.2f [%.2f, %.2f]", or, lo, hi))

**BSI (k = 6):** OR 2.39 (95% CrI 1.85–3.10), P(OR > 2) = 91%. The largest infection effect. Seven additional eligible studies had unreported event counts, raising selection concerns.

**IFI (k = 8):** OR 0.73 (95% CrI 0.53–1.00), P(OR < 1) = 97.5%. Probable protection, but driven by heterogeneous antifungal prophylaxis practices rather than a direct PTCy immunological effect. τ = 1.05 is dominated by a single zero-event study (Yanada 2026).
