Comparison 2: Haplo Proportion as Effect Modifier

The proportion of haploidentical donors in the PTCy arm varies substantially across C2 studies (0–100%). We tested whether this modifies the PTCy-vs-ATG treatment effect via frequentist meta-regression with haplo_pct as a continuous moderator.

plot_metareg <- function(es_df, fit, outcome_label) {
  df <- data.frame(
    haplo_pct = es_df$haplo_pct,
    or = exp(es_df$yi),
    wi = 1 / es_df$vi
  )

  newdat <- data.frame(haplo_pct = seq(0, 100, 1))
  pred <- predict(fit, newmods = newdat$haplo_pct)
  pred_df <- data.frame(haplo_pct = newdat$haplo_pct,
                         or = exp(pred$pred),
                         lo = exp(pred$ci.lb),
                         hi = exp(pred$ci.ub))

  ggplot(df, aes(x = haplo_pct, y = or)) +
    geom_hline(yintercept = 1, linetype = "dashed", colour = jama_grey) +
    geom_ribbon(data = pred_df, aes(y = or, ymin = lo, ymax = hi),
                alpha = 0.15, fill = jama_navy) +
    geom_line(data = pred_df, aes(y = or), colour = jama_navy, linewidth = 0.7) +
    geom_point(aes(size = wi), colour = jama_navy, alpha = 0.7) +
    scale_y_log10() +
    scale_size_continuous(range = c(1.5, 6), guide = "none") +
    labs(x = "Haplo donor %", y = "Odds Ratio",
         title = outcome_label,
         subtitle = sprintf("p = %.3f, R\u00B2 = %.0f%%", fit$QMp, fit$R2)) +
    theme_jama(base_size = 10)
}

NoteInterpretation

When PTCy is used with matched donors (0% haplo), the aGVHD advantage over ATG is large (predicted OR 0.34 [0.17–0.68]). At 100% haplo, this advantage is fully attenuated (OR 1.22 [0.52–2.91]). This is mechanistically coherent: HLA mismatch–driven alloreactivity in haplo transplants partially overwhelms the differential GVHD-suppressive benefit of PTCy relative to ATG. OS shows a suggestive but non-significant trend in the same direction (p = 0.13). CMV is unmoderated by donor type.

This finding was confirmed on both the primary C2 dataset (shown here, k = 8) and the sensitivity dataset including PTCy+ATG combo arms (k = 14, p = 0.039, R² = 31%).

Conditioning intensity. An additive model including both haplo proportion and MAC-predominant conditioning (k = 8, 1 study dropped for missing data) increased R² to 73%. The haplo coefficient strengthened (β = 0.015, p = 0.005) while the MAC term was suggestive but non-significant (β = −0.68, p = 0.14), pointing toward a possible independent MAC-associated enhancement of PTCy’s relative GVHD advantage. Importantly, haplo and MAC are not confounded — they pull in opposite directions — and the haplo moderator is robust to conditioning adjustment. A formal interaction term was not estimable at this sample size.

Publication Bias: RoBMA

Robust Bayesian model-averaging (RoBMA) jointly tests for the presence of an effect, heterogeneity, and publication bias by averaging across models with and without each component. P(effect) is the posterior probability that the true effect is non-zero; P(pub bias) is the posterior probability that selection models improve fit; BF(bias) is the corresponding inclusion Bayes factor.

WarningPublication Bias Assessment

RoBMA identifies strong evidence of publication bias for C1 OS (BF = 10.9) and C1 aGVHD (BF = 14.1), and moderate evidence for C2 OS (BF = 5.2) and C2 aGVHD (BF = 4.1). After bias adjustment, model-averaged posterior probabilities of a non-null effect are below 50% for all outcomes.

This does not mean the effects are definitively absent — it means the current evidence base cannot reliably distinguish true effects from publication-bias artifacts under RoBMA’s default skeptical priors (Normal(0, 1) on log-OR, 50% prior mass on the null). The bias evidence is strongest for the two outcomes with the largest apparent effects (C1 OS, C1 aGVHD), consistent with selective reporting amplifying favourable results in non-randomised comparisons. C1 CMV and C1 NRM show no meaningful evidence of bias (BF < 1).

## Comparison 2: Haplo Proportion as Effect Modifier {#sec-sens-c2-haplo}

The proportion of haploidentical donors in the PTCy arm varies substantially across C2 studies (0–100%). We tested whether this modifies the PTCy-vs-ATG treatment effect via frequentist meta-regression with `haplo_pct` as a continuous moderator.

```{r}
#| label: setup-metareg
#| include: false

# Load paired data and join haplo % from arms table
arms_df <- read_csv(file.path(extract_dir, "arms.csv"), show_col_types = FALSE)
studies_tbl <- read_csv(file.path(extract_dir, "studies.csv"), show_col_types = FALSE)

arm_haplo <- arms_df |>
  select(arm_id, donor_haplo_pct) |>
  mutate(haplo_pct = as.numeric(ifelse(donor_haplo_pct %in% c("NR", NA), NA, donor_haplo_pct)))

add_haplo_mod <- function(file) {
  read.csv(file.path(model_dir, file)) |>
    left_join(arm_haplo |> select(arm_id, haplo_pct), by = c("ptcy_arm_id" = "arm_id")) |>
    left_join(studies_tbl |> select(study_id, first_author, pub_year), by = "study_id")
}

mr_dat_os    <- add_haplo_mod("data_c2_os.csv")
```

## Interpretation

When PTCy is used with **matched donors** (0% haplo), the aGVHD advantage over ATG is large (predicted OR `r fmt_or(exp(pred_0$pred), exp(pred_0$ci.lb), exp(pred_0$ci.ub))`). At **100% haplo**, this advantage is fully attenuated (OR `r fmt_or(exp(pred_100$pred), exp(pred_100$ci.lb), exp(pred_100$ci.ub))`). This is mechanistically coherent: HLA mismatch–driven alloreactivity in haplo transplants partially overwhelms the differential GVHD-suppressive benefit of PTCy relative to ATG. OS shows a suggestive but non-significant trend in the same direction (p = `r sprintf("%.2f", fit_mr_os$QMp)`). CMV is unmoderated by donor type.

This finding was confirmed on both the primary C2 dataset (shown here, k = `r fit_mr_agvhd$k`) and the sensitivity dataset including PTCy+ATG combo arms (k = 14, p = 0.039, R² = 31%).

**Conditioning intensity.** An additive model including both haplo proportion and MAC-predominant conditioning (k = 8, 1 study dropped for missing data) increased R² to 73%. The haplo coefficient strengthened (β = 0.015, p = 0.005) while the MAC term was suggestive but non-significant (β = −0.68, p = 0.14), pointing toward a possible independent MAC-associated enhancement of PTCy's relative GVHD advantage. Importantly, haplo and MAC are not confounded — they pull in opposite directions — and the haplo moderator is robust to conditioning adjustment. A formal interaction term was not estimable at this sample size.
:::

## Publication Bias: RoBMA {#sec-sens-robma}

Robust Bayesian model-averaging (RoBMA) jointly tests for the presence of an effect, heterogeneity, and publication bias by averaging across models with and without each component. P(effect) is the posterior probability that the true effect is non-zero; P(pub bias) is the posterior probability that selection models improve fit; BF(bias) is the corresponding inclusion Bayes factor.

```{r}
#| label: setup-robma
#| include: false

robma_row <- function(file, label) {
  fit <- tryCatch(readRDS(file.path(model_dir, file)), error = function(e) NULL)
  if (is.null(fit)) return(NULL)
  # Extract from stored slots to avoid needing RoBMA loaded
  coefs <- fit$coefficients
  smry  <- fit$summary
  k     <- attr(fit$data, "k_final")
  
  mu_mean <- smry["mu", "Mean"]
  mu_lo   <- smry["mu", "0.025"]
  mu_hi   <- smry["mu", "0.975"]
  p_eff   <- coefs["mu (inclusion)"]
  p_bias  <- coefs["bias (inclusion)"]
  bf_bias <- p_bias / (1 - p_bias)  # convert inclusion prob to BF (prior odds = 1)
  
  data.frame(
    Analysis = label, k = k,
    OR_adj = sprintf("%.2f", exp(mu_mean)),
    CrI = sprintf("[%.2f, %.2f]", exp(mu_lo), exp(mu_hi)),
    P_effect = sprintf("%.1f%%", p_eff * 100),
    P_bias = sprintf("%.1f%%", p_bias * 100),
    BF_bias = ifelse(bf_bias > 1000, ">1000", sprintf("%.1f", bf_bias))
  )
}

robma_tbl <- do.call(rbind, Filter(Negate(is.null), list(
  robma_row("robma_c1_os.rds",    "C1 OS"),
  robma_row("robma_c1_nrm.rds",   "C1 NRM"),
  robma_row("robma_c1_agvhd.rds", "C1 aGVHD"),
  robma_row("robma_c1_cmv.rds",   "C1 CMV"),
  robma_row("robma_c1_bsi.rds",   "C1 BSI"),
  robma_row("robma_c1_ifi.rds",   "C1 IFI"),
  robma_row("robma_c2_os.rds",    "C2 OS"),
  robma_row("robma_c2_agvhd.rds", "C2 aGVHD"),
  robma_row("robma_c2_cmv.rds",   "C2 CMV")
)))
```

::: {.callout-warning}
## Publication Bias Assessment

RoBMA identifies **strong evidence of publication bias** for C1 OS (BF = 10.9) and C1 aGVHD (BF = 14.1), and **moderate evidence** for C2 OS (BF = 5.2) and C2 aGVHD (BF = 4.1). After bias adjustment, model-averaged posterior probabilities of a non-null effect are below 50% for all outcomes.

This does not mean the effects are definitively absent — it means the current evidence base cannot reliably distinguish true effects from publication-bias artifacts under RoBMA's default skeptical priors (Normal(0, 1) on log-OR, 50% prior mass on the null). The bias evidence is strongest for the two outcomes with the largest apparent effects (C1 OS, C1 aGVHD), consistent with selective reporting amplifying favourable results in non-randomised comparisons. C1 CMV and C1 NRM show no meaningful evidence of bias (BF < 1).
:::
